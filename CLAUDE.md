# AccessGuard AI - Gobernanza y Control de Accesos IAM

## Contexto
Predicción y automatización de solicitudes de acceso a recursos corporativos con el dataset Amazon Employee Access Challenge.

## Pila Tecnológica
- Python 3.10+
- Pandas, Scikit-Learn, XGBoost, CatBoost
- MLflow / Databricks
- Streamlit
- Git / GitHub

## Estructura
- `data/raw/`: Datasets originales (train.csv, test.csv)
- `notebooks/`: Trabajo exploratorio (EDA)
- `src/`: Código modular de procesamiento y entrenamiento
- `app/`: Aplicación de Streamlit
